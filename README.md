# 🍔 Cosmic Burger

**Космический конструктор бургеров** - интерактивное веб-приложение для создания идеального бургера с визуальными эффектами и Drag-and-Drop интерфейсом.

[![React](https://img.shields.io/badge/React-18.2-61dafb)](https://reactjs.org/)
[![Vite](https://img.shields.io/badge/Vite-5.0-646cff)](https://vitejs.dev/)
[![Redux](https://img.shields.io/badge/Redux-8.1-764abc)](https://redux.js.org/)

## Технологии

- **Frontend**: React 18, React Hooks
- **State Management**: Redux Toolkit, React-Redux
- **Drag-and-Drop**: @dnd-kit/core, @dnd-kit/sortable
- **Стили**: CSS Modules, CSS Variables
- **Сборка**: Vite
- **Анимации**: Keyframes, CSS Transitions
- **Drag-and-Drop конструктор**

## Основные возможности

**Выбор булки** - интерактивный выбор из доступных видов булок

**Добавление начинок** - выбор ингредиентов с визуальной анимацией

**Drag & Drop** - перетаскивание ингредиентов для изменения порядка

**Подсчет стоимости** - автоматический расчет итоговой цены

**Визуальный счетчик** - отображение количества каждого ингредиента

**Управление заказами**

**Оформление заказа** - создание заказа с генерацией уникального номера

**История заказов** - просмотр всех оформленных заказов

**Детали заказа**- информация о составе и итоговой стоимости
